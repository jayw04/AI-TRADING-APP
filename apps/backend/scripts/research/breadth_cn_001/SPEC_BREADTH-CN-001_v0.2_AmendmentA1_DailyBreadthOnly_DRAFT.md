## 1. 假设、结论空间与证伪(已按 3 天无止损持有重新核对)

**H1-D**:全 A(SH/SZ)"站上 5 日均线比例"处于历史高区(分位 ≥ 80%)并首次回落时做空 IC、处于低区(≤ 20%)并首次回升时做多 IC,固定持有 3 个交易日,扣除成本后在开发期盈利,且显著优于对照。

**结论只有三种**:PASS-IN-SAMPLE / REJECT / **INCONCLUSIVE**。按下面顺序判定:

1. **F3(样本量)先判**:开发期 *被接受的* 交易(扣除重叠忽略后)**总数 < 40** → **INCONCLUSIVE**。INCONCLUSIVE 既不是通过也不是否决:不得改参数重跑,封存期保持封存,只允许如实报告。单一方向交易数 **< 15** 时,该方向的结果不得作为证据(只列出,不下结论)。封存期被接受交易数 **< 10** → 封存期结论为 INCONCLUSIVE。(40 来自 v0.1;15 与 10 经 Jay 确认,2026-10-16。**这三个数字是"最低报告下限",不是统计功效**:达到下限只表示结果可以被报告,不表示检验有足够的功效发现真实效应。)
2. **F1(盈亏)**:主结论臂开发期扣费后总盈亏 ≤ 0,或 PF < 1.2 → REJECT。
3. **F2(对照)**:见下,p > 0.05 → REJECT。

### 对 v0.1 每条证伪条件的重新核对

| v0.1 条件 | 在"3 天固定持有、无止损"下是否仍然有效 | 处理 |
|---|---|---|
| F1:总盈亏 ≤ 0 或 PF < 1.2 | **仍然有效,但只是必要条件。** PF 1.2 原为"止损型、盈亏不对称"的策略校准;固定持有没有止损造成的不对称,且亏损尾部无上限。样本只有数十笔时 PF 噪声很大,通过 F1 不构成技能证据 | 保留阈值;新增必报:单笔最大亏损、最大回撤;**判定的实质检验是 F2** |
| F2:随机日期对照,统计量为总盈亏,p>0.05 即否决 | **原写法失效。** (i) 重叠规则会让"被接受交易数"在真实与对照之间不同,总盈亏随数量变化,比较不公平;(ii) 均匀随机日期会打散预备信号在时间上的成团性,使重叠规则在对照中的触发方式与真实不同;(iii) v0.1 的 F2 是为排除"MA60 趋势跟随本身盈利"而设,本试验已没有 MA60,F2 现在直接检验广度的择时价值 | **统计量改为"每笔被接受交易的平均净盈亏"**(分多空与合计)。**主对照 = 循环平移对照**:把开发期内全部预备信号的日期序列整体平移 k 个交易日(首尾相接),保持信号数、多空顺序和间隔不变,因此重叠规则与真实情形同样触发。**平移量集合与随机种子已在冻结前固定**:500 个互不相同的平移量,取自 [20, L−20](与原位置的循环距离在两个方向上都 ≥ 20 个交易日,即 |平移| < 20 被排除),L = 1,756 个交易日(2016-10-17 至 2023-12-31,依 Tushare SSE 日历),种子 20261016;集合文件 `circular_shift_set_dev.csv`(身份以与换行符无关的**集合摘要** `dfc372393370c301a7b681fc657e7f8ef44b4120505997cd217cc7000fedc594` 为准,由 `test_shift_set.py` 核对;文件本身的 SHA-256 随换行符变化,故不作身份),生成代码 `shift_set.py`。冻结前若交易日历有更正导致 L 改变,只能在冻结前重新生成并登记,冻结后不得更改;n = 500。**次对照 = v0.1 的随机日期对照**(多空数量不变),仅作敏感性。两种对照都使用同样的主力规则、到期资格(§3a)、成本与重叠规则;单侧 p = (1 + #{对照 ≥ 实际})/(n+1) |

## 2. 信号(沿用,不新增参数)

**价格口径(确认)**:广度使用**复权收盘价** close_adj = 原始收盘价 × 复权因子(v0.1 C10 已规定"用复权价";此处补充定义)。只有同一只股票自身的比值有意义,因子方向(前复权/后复权)只需在该股票内一致;MA5 与"站上"判断都在 close_adj 上做,原始未复权价只用于数据检查。除权日因子缺失的行按"无复权因子"排除并计数(不默认 1.0)。

`Config` 取 v0.1 的值:`measure=ratio`、`ma_len=5`、`ma_max_span=10`、`pct_warmup=500`、`high_pct=0.80`、`low_pct=0.20`、`zone_on=prev`。预备信号 T 日收盘后形成(C4/C5)。广度序列自 2014-01-02 起算(C3)。

## 3. 交易规则(最小版)

记预备信号形成日为 T,入场日 E = T+1,出场日 X = T+4(即 E 之后第 3 个交易日)。

1. **入场**:E 日 **开盘**,按 §4 选出的合约开 1 手,方向同信号。
2. **出场**:X 日 **开盘** 平仓。持有 H = 3 个交易日,取 v0.1 的 `setup_valid_days`,不引入新自由度。
3. **只持一个合约**:持到出场,**不移仓**,不使用差值复权序列,盈亏全部按该真实合约的成交价计算。
4. **(a) 到期资格**:在 T 日收盘选合约时,**候选合约必须满足:从 E 日起(含 E)到该合约最后交易日(含)至少还有 4 个交易日**(即最后交易日 ≥ X)。不满足者被排除,主力规则只在满足者中排序(规则 V:前一交易日成交量最大;规则 O:前一交易日持仓量最大)。因此**不会出现"到期日前被迫提前平仓"**,原 §3 的提前平仓例外与 A1-4 作废。被排除而发生改选的次数与日期在报告中单列。最后交易日按 CFFEX 规则(每月第三个周五,遇节假日顺延)由 CFFEX 日历给出(B1 已对 140/140 个可核对合约一致)。
5. **(b) 重叠信号规则**:一笔交易占用从 E 日开盘到 X 日开盘的区间。后续在 T′ 日收盘形成的新预备信号,其入场日 E′ = T′+1:
   - 若 **E′ < X**(仓位仍未平):**忽略**,不加仓、不反手、不顺延,记录被忽略的次数、日期与方向;
   - 若 **E′ = X**:**接受**——旧仓在 X 日开盘平仓,新仓在同一开盘开仓,两边各自计成本,不对冲轧差;
   - 若 **E′ > X**:正常接受。
   同一天只会有一个预备信号,无并列。先到先得。反手作为敏感性,不进入主结论。
6. 固定 1 手,每点 200 元,最小变动 0.2 点(CFFEX 合约表)。

## 4. 主力合约规则(D5)

两种规则对同一冻结配置**并列运行并分别报告**。

**A1-1 决定(Jay,2026-10-16 会话指示):规则 V(前一交易日成交量最大的合格合约)为主结论臂;规则 O(持仓量最大)为敏感性臂。** 记录的理由是设计理由,不是结果:规则 V 选出的合约最接近指数(最活跃的近月合约,与现货的价差与贴水最小),因而把基差/贴水收益挡在主结论之外;规则 O 倾向选中套保盘集中的远月合约,贴水更深。PASS/REJECT/INCONCLUSIVE 只依据主结论臂;规则 O 的结果只作披露,不得用来替换主结论。
背景比较数据属个人使用许可数据衍生,仅见 owner-only 的 B3 汇总,不写入本规格,也不进入周会材料(PU-1)。

## 7. 必须报告的分解与明细

- **盈亏分解(两个主力规则各一份)**:每笔交易总盈亏 = **价格方向部分** + **基差/贴水部分**。方向部分 = 方向 × (现货指数在出场日开盘 − 入场日开盘)× 乘数,其余归基差部分。多空**分开**报告(IC 长期贴水,多头天然获得收敛、空头天然承担成本)。
- **(e) 中证500现货指数开盘价来源(已固定)**:主来源 **Baostock `sh.000905` 日线 `open`**;核对来源 **掘金 `SHSE.000905` 日线 `open`**。已核对:2016-07-01 至 2026-10-16 两源各 2,498 个交易日,与 Tushare SSE 交易日历逐日吻合,开盘价在 0.001 内全部一致。注意:一致只说明两源互相印证,**不证明独立**(很可能同一上游)。指数开盘价由 09:25 集合竞价后成分股开盘价计算,IC 在 09:30 开始连续交易,存在小的时点错位,故方向部分是近似量,须在报告中如实注明。
- 胜率、盈亏比、PF、最大回撤、单笔最大亏损、分年、分多空、持仓分布、手续费占比、被忽略信号数(按方向)、到期资格改选次数。
- 对照:同时报告基差部分的对照分布,避免把贴水收益误当作择时收益。
