## 1. 可检验假设与证伪条件

**H1(主假设)**:全A股"站上5日均线比例"处于历史高区并首次回落时做空IC、处于低区并首次回升时做多IC,配合30分钟MA60确认与止损,扣除成本后在开发期盈利,且**显著优于把同样数量的拐头信号随机放到其他日期**的对照组。

**证伪(任一成立即 REJECT,不在同一段数据上调参挽救)**:
- F1 开发期扣费后总盈亏 ≤ 0,或盈利因子 PF < 1.2;
- F2 随机日期对照(`null_test`,n=500)单侧 p > 0.05 —— 说明收益来自"30分钟MA60趋势跟随"本身,与情绪广度无关;
- F3 开发期交易数 < 40(样本不足,结论为 NOT EVALUABLE 而非 PASS)。

> F2 是本策略最关键的检验。IC 在 2016–2026 有多段大趋势,MA60 进出场本身可能盈利;只有超过随机对照,才能说"情绪广度"有用。

## 2. 指标定义(含对原始需求的澄清,需周会确认)

| # | 原始描述 | 本规格采用 | 理由 |
|---|---|---|---|
| C1 | 低区和高区均为历史20%分位以下 | **高区 = 分位 ≥ 80%;低区 = 分位 ≤ 20%** | 原文应为笔误,两区不可能同为20%以下 |
| C2 | 统计站上5日均线的**个股数量** | **主指标用比例**(站上数 / 合格股票数);数量作诊断 | A股可交易股票数十年内从约3000只增至5000只以上。用数量算10年分位,早年会机械性落入低区、近年落入高区,信号由扩容驱动而非情绪 |
| C3 | 以历史分位为基准 | **时点分位**:第T日只用≤T日的历史(扩展窗口),预热≥500交易日;广度序列从2014年起算 | 全样本分位用到了未来数据,回测结果会虚高 |
| C4 | 拐头:高区指标第一天回落 | 空头预备@T:T-1日处于高区,且 B(T)<B(T-1) 且 B(T-1)≥B(T-2);多头对称 | 以拐点前一日(峰/谷)判区,避免"当日跌出高区"漏掉信号;`zone_on='today'` 作为敏感性 |
| C5 | (未说明) | 日线广度T日收盘后才可得 → **预备信号T+1起生效,有效期3个交易日**;新预备信号覆盖旧信号 | 时序必须明确,否则无法回测;有效期是新增自由度,预先冻结为3 |
| C6 | 30分钟价格跌破/突破60均线 | **状态判定**:预备期内某根30分钟K线收盘价位于MA60下方(做空)/上方(做多)即触发,**下一根K线开盘价成交**;同一预备信号只开仓一次 | 防止止损后在同一信号内反复进出 |
| C7 | 止损:重新突破/跌破60均线 | 30分钟收盘价反向穿越MA60 → 下一根开盘平仓。**止损即唯一出场**,无止盈、无时间止损 | 按原文执行;持仓时间可能较长,结果中报告持仓分布 |
| C8 | 当月主力合约 | **D日主力 = D-1日收盘持仓量最大且未到期的IC合约**,换月日开盘移仓 | "当月"与"主力"在到期前约一周通常不同;按持仓量规则。"始终当月合约"作为敏感性 |
| C9 | (未说明) | MA60 用**差值复权连续价**计算;盈亏用实际合约成交价 | 换月价差会制造虚假穿越 |
| C10 | 股票池剔除ST、*ST、退市整理、N、C | 剔除标记必须是**当日时点状态**;股票池**包含已退市股票**;停牌日不计入分子分母;用复权价 | 防止幸存者偏差与除权日假信号 |

## 3. 交易规则(冻结版)

- 标的:IC 主力(C8),多空双向,固定1手(每点200元,最小变动0.2点)。
- 做空:空头预备有效期内,30分钟收盘 < MA60 → 次根开盘开空;30分钟收盘 > MA60 → 次根开盘平仓。
- 做多:多头预备有效期内,30分钟收盘 > MA60 → 次根开盘开多;30分钟收盘 < MA60 → 次根开盘平仓。
- 持仓遇换月:旧合约最后一根收盘平、新合约次根开盘开,两边计成本。
- 同时出现平仓与反向开仓条件时:先平后反手。

## 5. 成本模型

- 滑点:每边1跳(0.2点)。
- 手续费:开仓、平仓、**平今**分别计费,费率按中金所**现行**标准核对后冻结(代码中为占位值)。
- **历史时期警示**:2015年9月起股指期货交易受限(平今手续费大幅提高、开仓手数限制、保证金提高),2017–2019年逐步放宽。本策略30分钟级止损可能当日平仓,2016–2018年的结果须按当时费率重算并单独标注可实现性;若该时期按当时规则不可交易,开发期改为可交易起点,并在台账记录。
- **基差**:IC长期贴水,多头天然获得基差收敛收益、空头天然承担成本。多空结果必须**分开报告**;随机对照保持多空信号数量不变,可部分控制该偏差。

## 6. 评估设计

| 区段 | 时间 | 用途 |
|---|---|---|
| 预热 | 2014-01 → 2016-10 | 仅用于均线与分位预热,不计交易 |
| 开发期 | 2016-10-17 → 2023-12-31 | 规则检验、随机对照、辅助指标筛选 |
| 封存样本外 | 2024-01-01 → 最新 | **一次性**打开,仅对冻结配置 |

- **单次决定性运行**:冻结配置在开发期跑一次即为结论;仅允许修复代码缺陷后重跑,并在台账注明。
- **试验台账**:每次运行自动写入 `trial_ledger.csv`(配置摘要、区段、交易数、参数、备注)。
- **封存机制**(代码强制):`segment='holdout'` 要求台账中已有该配置的 `FREEZE` 记录,且每个配置只能打开一次,否则抛出 `HoldoutSealed`。
- **开发期 PASS 条件**:F1、F2、F3 均未触发 → PASS-IN-SAMPLE → 进入封存期。
- **封存期 PASS 条件**:扣费总盈亏 > 0,PF ≥ 1.0,随机对照 p ≤ 0.10。
- 报告:胜率、盈亏比、PF、最大回撤、分年、分多空、持仓时长、手续费占比。
- 敏感性(只诊断,不改变结论):`zone_on='today'`、有效期 K=1/5、数量口径、"始终当月合约"。

## 7. 第四部分(指标增强)的治理规则

"用AI或量化方法筛选辅助指标"本身是一个搜索过程,搜索次数越多,偶然找到"有效"指标的概率越高。因此:

1. **先完成 H1 检验**。H1 REJECT 时,辅助指标不能用于挽救主信号(否则等于换了一个策略,需另立编号)。
2. 候选辅助指标**事先列出并设上限**(建议 ≤ 10 个),每个候选写入台账,结论中披露候选总数。
3. 筛选只在开发期内用**前推(walk-forward)**方式进行;封存期只对最终冻结的一个组合打开一次。
4. 所有辅助数据必须时点可得。候选方向(假设,非结论):IC 年化基差分位、全A成交额/换手广度、涨跌停家数比、中证500已实现波动率、500/300 相对强弱、两融余额变化。注意:北向资金每日实时净流入自2024年8月起不再公开披露,样本外不可用,不建议纳入。

## 8. 周线 / 月线扩展

- 代码已支持 `period_breadth(freq='W'|'M')`,只用已完成周期的收盘数据。
- **月线样本量警示**:10年仅约120个月度观测,高/低区拐头预计每年不足一次,作为独立交易信号**无法统计检验**。建议月线仅作为**环境过滤**(例如只在月线非高区时做多),且须作为新的冻结试验登记,不与日线结论混用。
- 周线(约520个观测)可在日线结论之后作为第二个试验。
